# 选股分析真实进度设计

## 目标

把前端循环播放的模拟步骤替换成后端真实任务状态，展示当前阶段、百分比、训练状态、详情和累计耗时。

## 架构

保留现有同步 `/api/select/`。新增：

- `POST /api/select/start/`：创建后台线程任务，返回 `task_id`。
- `GET /api/select/progress/?task_id=...`：返回任务状态；完成时附带原选股响应。

任务状态保存在当前 Django 进程内，适用于本地 `--noreload` 单进程运行。服务重启后任务状态清空。
使用线程局部变量把进度回调传入现有同步选股流程，避免大规模改写函数签名。

## 状态

状态字段包含 `state`、`stage`、`percent`、`message`、`detail`、`elapsed_seconds`。
阶段覆盖初始化、股票池与缓存、行情数据、板块过滤、训练、因子与预测、结果整理、完成和失败。
未勾选训练、样本不足、训练成功或训练失败均明确展示。
