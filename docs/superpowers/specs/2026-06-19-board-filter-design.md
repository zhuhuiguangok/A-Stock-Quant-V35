# 科创板与创业板预过滤设计

## 目标

允许用户在开始选股分析前分别排除创业板和科创板股票，默认均排除。过滤发生在股票池生成后、
任何行情和因子接口请求前，以减少请求量并确保相关股票不进入训练、择时和选股模型。

## 交互与参数

控制面板新增两个复选框：

- `exclude_chinext`：排除创业板，默认 `true`
- `exclude_star`：排除科创板，默认 `true`

前端随 `/api/select/` POST 请求发送这两个布尔值。后端只接受真正的 JSON 布尔值；
缺省时按 `true` 处理。后端同时采用请求中的 `stock_pool`，并限制为
`csi1000`、`csi2000`、`all`，无效值回退到配置默认值。

## 过滤规则

- 创业板：证券代码数字部分以 `300` 或 `301` 开头。
- 科创板：证券代码数字部分以 `688` 或 `689` 开头。

过滤函数接收股票代码列表并返回保持原顺序的新列表。过滤完成后记录过滤前、过滤后及各板块排除数量。

## 缓存

行情缓存文件名加入过滤标记，避免不同条件共享缓存：

```text
real_data_<pool>_cyb<0|1>_star<0|1>_<start>_<end>.parquet
```

其中 `1` 表示排除该板块。

## 测试

- 单元测试覆盖两个板块分别排除、同时排除、均不过滤及顺序保持。
- 请求测试 mock 数据获取函数，验证前端参数传递到数据层，并验证股票池参数被采用。
- 页面测试验证两个默认勾选的复选框以及 POST 请求字段存在。
- 运行 Django 全量测试、系统检查并请求本地首页。
